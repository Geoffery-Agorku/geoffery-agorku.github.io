# geoffery-agorku.github.io

Updated static portfolio website for GitHub Pages.

## Structure

- `index.html`: homepage
- `about.html`: biography, education, and skills
- `projects.html`: selected research systems and projects
- `publications.html`: publications, preprints, and technical reports
- `presentations.html`: conference presentations and invited talks
- `honors.html`: fellowships, awards, leadership, and service
- `styles.css`: responsive site styles
- `assets/site.js`: mobile navigation
- `assets/documents/Geoffery_Eyram_Agorku_CV.pdf`: academic CV
- `assets/images/`: optional project and profile images

## Local preview

Open `index.html` in a browser or use a local static server.

## Publish

Copy these files into the root of the `Geoffery-Agorku/geoffery-agorku.github.io` repository, then commit and push to `main` after reviewing all text and links.
